# Rakushinsha

Research and source files for the William C. C. Chen dossier.

## Published site

[william-cc-chen-dossier.pages.dev](https://william-cc-chen-dossier.pages.dev/)

## Contents

- `site/index.html` — William C. C. Chen research dossier
- `site/more-fuel-for-the-cells.html` — English translation of the 2009 breathing article
- `wikipedia-ja-draft.wiki` — cited Japanese Wikipedia draft

## Local preview

Serve the `site` directory with any static HTTP server. For example:

```sh
python3 -m http.server 8000 --directory site
```

Then open <http://localhost:8000>.

Research downloads, scraper output, and local Wrangler state are intentionally excluded from version control.
